Breaking changes in low-level APIs: `GanttCanvasComponent.selectionChange` is no longer emitted (listen to `selectionChange` on `<gantry>`, which now reports every selection); `GanttKeyboardDirective` reads the rows from the layout and needs `GanttDragService` (provided by `<gantry>`), its `visibleRows` input is ignored; `GanttDataSource.page()` is the last page loaded (0 before the first load) and `createGanttDataSource()` no longer needs an injection context; `GanttLabels` has new required members — `loadError`, `retry`, `colId`, `colType`, `colStatus`, `colPredecessors`, `colBaselineStart`, `colBaselineEnd`, `colVariance`, `statusNotStarted`, `statusInProgress`, `statusOverdue`, `statusDone`, `typeTask`, `typeMilestone`, `typeGroup`, `ariaTaskList`, `dependency(name, type, lagDays)` and `varianceDays(days)` (only objects typed as a full `GanttLabels` need them — `options.labels` stays partial). The default split panel shows `name`, `start`, `end`, `progress` (Duration moved to the table view; restore it with `panel: { columns: ['name', 'start', 'end', 'duration', 'progress'] }`). `ColumnCellContext` gains `ctx`; `<ng-template ganttColumn>` inputs left unset inherit from a built-in column with the same key.
