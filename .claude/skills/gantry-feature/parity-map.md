# Parity map: where each concern lives

| Concern                                     | Core (computes)                                                                      | Web Component (paints)                                                                       | Angular (paints)                                                                                                                          |
| ------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Option defaults                             | `render/config.ts` `resolveConfig`                                                   | `engine/graph/config.ts` (`config`)                                                          | `layout/gantt-layout.service.ts` `cfg` (bound by `gantry.component.ts`)                                                                   |
| Header tiers, week formats, zoom presets    | `render/scales.ts`                                                                   | `layers/header.ts`                                                                           | `header/gantt-header.component.ts`                                                                                                        |
| Range, delimiters, bands, today, `toX`      | `render/timeline.ts` `buildTimeline`                                                 | `engine/graph/timeline.ts`, `layers/static.ts`                                               | layout service `timeline`, `layout/gantt-canvas.component.ts`                                                                             |
| Row geometry, windows                       | `render/timeline.ts` `computeRowGeometries`, `render/virtual.ts`, `render/window.ts` | `engine/graph/{rows,windows,horizontal}.ts`                                                  | layout service `rowGeometries`, `vWindow`, `hWindow`                                                                                      |
| Bars, labels, handles, focus ring, hit test | `render/bars.ts` `computeBarVisual` / `hitTestBar`                                   | `paint/bars.ts`, `layers/bars.ts` (+ overlay)                                                | `bars/builtin-bar.ts` (+ 3 thin components), `bars/bar-outlet.directive.ts`, `bars/bar-overlay.component.ts`, `bars/bar-focus.service.ts` |
| Dependency arrows                           | `render/arrows.ts` `computeArrowVisual`                                              | `paint/arrows.ts`, `layers/arrows.ts`                                                        | `arrows/gantt-arrow.component.ts`                                                                                                         |
| Drag / resize, gestures, auto-scroll        | `render/drag.ts` `DragSession`, `interaction/{gesture,autoscroll}.ts`                | `interaction/{canvas-pointer,drag,gestures,autoscroll}.ts`                                   | `drag/gantt-drag.service.ts`, `layout/gantt-canvas.component.ts`, `scroll/gantt-scroll.service.ts`                                        |
| Keyboard, focus, move mode                  | `interaction/{keymap,grid-nav,timeline-nav,roving,key-selection,keyboard-edit}.ts`   | `interaction/{keyboard,grid-keys,timeline-keys,keyboard-edit}.ts`, `layers/focus-restore.ts` | `selection/gantt-keyboard.directive.ts`, `a11y/{grid-keys,timeline-keys}.ts`, `drag/keyboard-edit.ts`                                     |
| Announcements, accessible names             | `interaction/announce.ts` `createAnnouncer`, `a11y/describe.ts`                      | `engine/announce.ts` (`ctx.announce`)                                                        | `a11y/announcer.ts`                                                                                                                       |
| Zoom gestures, fit to screen                | `render/zoom.ts`, `render/viewport.ts`                                               | `interaction/zoom.ts`, `layers/scroll-commands.ts`, `gantry.element.ts` `fitToScreen`        | `scroll/zoom-gestures.ts`, `gantry.component.ts` `fitToScreen` / `syncHorizontalScroll`                                                   |
| Tooltip                                     | `state/tooltip.ts` (`buildTooltipModel`, `reduceTooltip`, `placeTooltip`)            | `layers/tooltip.ts`, `interaction/tooltip-triggers.ts`                                       | `tooltip/{tooltip-state,gantt-tooltip.component,gantt-tooltip-template.directive}.ts`                                                     |
| Drag readout                                | `render/readout.ts`                                                                  | `layers/readout.ts`                                                                          | `drag/gantt-drag-readout.component.ts`                                                                                                    |
| Marker lane, annotations                    | `render/markers.ts`                                                                  | `engine/graph/markers.ts`, `layers/header.ts`, `layers/overlay.ts`                           | layout service `markerLane`, `header/gantt-header.component.ts`, `layout/gantt-annotations.component.ts`                                  |
| Toolbar                                     | `state/toolbar.ts` `buildToolbar` (`types.ts` `GanttToolbarOptions`)                 | `layers/toolbar.ts`, `dom/icons.ts`                                                          | `annotations/gantt-toolbar.component.ts`, `icons/gantt-icon.component.ts`                                                                 |
| Legend                                      | `state/legend.ts` (`buildLegend`, `legendPlacement`)                                 | `layers/legend.ts`                                                                           | `legend/gantt-legend.component.ts`                                                                                                        |
| Loading / error / empty states              | `state/chart-state.ts`                                                               | `engine/graph/states.ts`, `layers/states.ts`                                                 | layout service `chartState`, `states/gantt-chart-state.component.ts`                                                                      |
| Theme palettes, CSS vars                    | `render/theme.ts`                                                                    | `engine/graph/chrome.ts` (`themeCss`), `styles/theme-sheet.ts`                               | `services/gantt-theme.service.ts`                                                                                                         |
| Forced colors                               | — (CSS only, system colours)                                                         | `styles/forced-colors.css.ts`                                                                | each component's `styles` (`@media (forced-colors: active)`)                                                                              |
| Columns, sort comparator                    | `gantt-data.ts`, `render/columns.ts`                                                 | `interaction/columns.ts`, `layers/tasklist.ts`                                               | `columns/…`, `tasklist/gantt-tasklist.component.ts`                                                                                       |
| Panel, splitter, views, state               | `types.ts`, `state/view.ts`, `state/persistence.ts`                                  | `gantry.element.ts`, `interaction/splitter.ts`                                               | `gantry.component.ts`                                                                                                                     |
| Public surface                              | `src/index.ts`                                                                       | `src/types.ts`, `src/index.ts`, `engine/props.ts`                                            | `src/public-api.ts`                                                                                                                       |

Paths are relative to `packages/core/src`, `packages/vanilla/src` and `packages/angular/src/lib`.

Wrappers: `packages/react/src/index.tsx` and `packages/vue/src/Gantry.ts` derive props and
events from `GANTRY_PROPERTIES` / `GANTRY_EVENTS`; `packages/svelte/src/Gantry.svelte` lists
them explicitly.

Tests: core → `packages/core/src/__tests__/` (Node); Web Component →
`packages/vanilla/src/__tests__/` (happy-dom); Angular → `packages/angular/src/lib/*.spec.ts`
(`pnpm test:angular`, new specs in new files); wrappers → `packages/{react,vue,svelte}/src/__tests__/`.
Real-browser behaviour (paint parity, a11y, forced colors, CSP, gestures) → `e2e/*.spec.ts`.
